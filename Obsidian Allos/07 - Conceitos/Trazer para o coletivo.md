# Trazer para o coletivo

> [!abstract] Definição
> Técnica para aliviar a potência de uma intervenção que carrega uma hipótese direta: formulá-la como generalidade sobre 'as pessoas' ou 'a gente', frequentemente apoiada em saberes de senso comum.
> — [[Alan 16 - Intervenção]] [▶ 1:37:24](https://www.youtube.com/watch?v=jUT9-AyGPgM&t=5844s)

**Exemplo usado:** 'Não sei se você já reparou, mas às vezes a gente trata os outros do jeito que a gente é.'
