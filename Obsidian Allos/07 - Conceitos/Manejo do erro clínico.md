# Manejo do erro clínico

> [!abstract] Definição
> O erro importa menos que o que se constrói depois. 'Erro clínico não existe tanto; o que existe é não saber lidar com o que aconteceu.'
> — [[Prática Clínica 05 - Setting e taxonomia das habilidades clínicas]] [▶ 1:39:19](https://www.youtube.com/watch?v=do6RPg_flrg&t=5959s)

**Exemplo usado:** Uma intervenção espontânea de uma participante num estágio ganhou sentido clínico pelo que ela construiu em seguida.
