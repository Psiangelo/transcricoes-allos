# Objetivo de curto prazo

> [!abstract] Definição
> Requisito intermediário para o grande objetivo (passo 4), descoberto por uma cadeia de porquês. A cadeia não é necessariamente linear.
> — [[Monitoria 21 - Diogo - Sete passos da tomada de decisão clínica]] [▶ 0:51:05](https://www.youtube.com/watch?v=vzdTMHyqipM&t=3065s)

**Exemplo usado:** Questionar convicções → mostrar que não é intocável → contato com o que sente → consciência dos atos → responsabilização.
