# Pergunta estruturada

> [!abstract] Definição
> Pergunta mais dirigida, às vezes fechada, usada quando o paciente está rígido ou perdido para dar a ele estrutura para responder, abrindo depois ('um passo para trás para dar dois para frente').
> — [[Acervo 16 - Duelo de abordagens e encerramento de sessão]] [▶ 1:10:15](https://www.youtube.com/watch?v=n1iu-W8ujac&t=4215s)

**Exemplo usado:** 'Em outros momentos foi difícil fazer escolhas?' 'Sim.' 'Quando?'
